# UX and UI Checklist

## UX Review
- Evaluate whether core tasks are obvious within 5 seconds on each screen.
- Confirm user mental model: story, source, bias, confidence, and updates are clearly differentiated.
- Check error, empty, and loading states for clarity and recovery paths.
- Verify notification and background refresh behavior is explainable and controllable.
- Assess onboarding for consent, expectation-setting, and trust.

## Accessibility
- Check color contrast, touch target size, and focus order.
- Ensure screen-reader labels are meaningful for cards, badges, and controls.
- Verify dynamic type and font scaling support without layout breakage.
- Confirm motion/animation does not block comprehension and respects reduced-motion preferences.

## UI Design Quality
- Verify hierarchy consistency: typography scale, spacing rhythm, and visual grouping.
- Flag noisy layouts that obscure top story signals.
- Check consistency of components (cards, badges, chips, rails, buttons).
- Confirm color semantics are stable (risk levels, source reliability, bias direction).
- Assess visual density and whitespace balance across feed and detail surfaces.

## Trust and Explainability
- Require clear explanations for ranking/matching decisions.
- Ensure source credibility cues are visible and not misleading.
- Check that uncertainty is communicated without false precision.
- Verify links to original sources are prominent and preserved.
