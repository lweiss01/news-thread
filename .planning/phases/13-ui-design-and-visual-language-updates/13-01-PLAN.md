# Plan 13-01: Visual Foundations & Amber Brand

Implement the core "Amber Brand" identity by updating the design tokens, global themes, and shape definitions. This sets the stage for all subsequent UI refinements.

## Tasks

<task>
### Update Color.kt with new tokens
Update `Color.kt` to include the verified Amber palette, Orange500 for low reliability, and the new Credibility-related aliases.
**Validation:** Check `Color.kt` contains `Amber500`, `Orange500`, `CredHigh`, `CredMedium`, `CredLow`, and `CredUnrated`.
</task>

<task>
### Update Theme.kt for Amber Brand
Update `NewsThreadTheme` to ensure `Amber500` is the primary color. Enforce `dynamicColor = false` to preserve brand identity. Update the color schemes for both Light and Dark modes.
**Validation:** Verify `dynamicColor` is set to `false`. Check that `Primary` is mapped to `Amber500`.
</task>

<task>
### Refine Shape Tokens
Update `Shape.kt` to use rounder corner radii (rx: 12-16) for Small, Medium, and Large shapes to match the "Softened" design direction.
**Validation:** Check `Shape.kt` for `RoundedCornerShape` values between `12.dp` and `16.dp`.
</task>

## Must-Haves
- `Amber500` is the Primary brand color.
- Dynamic color is disabled.
- Shapes are softened with global 12-16dp radius.
