# Phase 13.1.1: Visual Polish and Parity

## Goal
Achieve 1:1 visual parity with the provided design mockups in `newsthread_design_refresh`.

## Context
Initial implementation of Phase 13 and 13.1 captured the color palette but missed several signature layout elements:
- Bias spectrum footer bars on article cards.
- "+ Track" action pattern in card footers.
- Journalistic typography weights (Amber source names, Slate950 background).
- High-fidelity icon rendering (gradients and precise pathing).

## Key Deliverables
1. **Refined ArticleCard**: Spectrum footer + track button + improved spacing.
2. **Refined ComparisonScreen**: High-fidelity headers + "Read original story ▶" glyph styling.
3. **High-Fidelity Icon**: Adaptive icon with proper gradients and vector paths.
